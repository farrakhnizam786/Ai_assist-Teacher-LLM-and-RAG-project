# 📚 Detailed Project Documentation & Engineering Journey

## 📁 1. File & Function Breakdown (Files aur Functions ka Kaam)

### A. transcribe.py (Audio Extraction & Transcription Module)
* **`convert_video_to_mp3(video_path, audio_path)`**:
  * *Kaam:* MoviePy library ka use karke input video file se raw audio ko .mp3 format mein extract karta hai.
  * *Change karne par kya asar hoga:* Agar aap audio format ya codec (`libmp3lame`) badlenge, toh audio ki compatibility ya file size par asar pad sakta hai.
* **`transcribe_and_optimize_chunks(audio_path, json_path)`**:
  * *Kaam:* OpenAI-Whisper model load karta hai, audio ko text mein transcribe karta hai, aur chote-chote segments ko combine karke ~400 characters ke optimized chunks banata hai.
  * *Change karne par kya asar hoga:* Agar chunk size chota karenge toh context toot sakta hai; agar bohot bada karenge toh LLM par token load badh jayega.

### B. rag_pipeline.py (Vector Search, Embedding & LLM Generation Module)
* **`get_chroma_collection(db_path)`**:
  * *Kaam:* ChromaDB ka persistent client initialize karta hai taaki vector database local disk par save rahe.
* **`store_chunks_in_chroma(json_path, db_path)`**:
  * *Kaam:* Sentence-Transformers (`all-MiniLM-L6-v2`) ka use karke text chunks ki embeddings banata hai aur unhe metadatas (timestamps) ke sath ChromaDB mein index karta hai.
* **`retrieve_top_chunks(query, collection, top_k)`**:
  * *Kaam:* Student ke question ki embedding nikal kar ChromaDB mein semantic similarity search run karta hai aur top matching chunks pull karta hai.
* **`format_time(seconds)`**:
  * *Kaam:* Raw seconds ko user-friendly MM:SS format (jaise 02:19) mein convert karta hai.
* **`generate_ai_tutor_response(query, top_chunks)`**:
  * *Kaam:* Ek professional AI Teaching Assistant prompt (Role, Constraints, Fallback, Output Format) taiyar karta hai aur Groq LLM API ko call karke exact answer generate karwata hai.

### C. main.py (Master Orchestrator)
* **Kaam:** Saare modules (`transcribe.py` aur `rag_pipeline.py`) ko ek sequential flow mein connect karta hai. Isko run karte hi poora pipeline (Video -> MP3 -> Transcription -> ChromaDB -> Retrieval -> LLM Answer) automatic execute ho jata hai.

## 🛠️ 2. Changes Made During Development (Humne Kya-Kya Improvements Kiye)
* **Explicit Video-to-MP3 Step:** Direct video transcription se move karke moviepy ke zariye proper audio extraction add kiya taaki pipeline zyada robust bane.
* **Chunk Optimization (Bonus Feature):** Whisper ke raw short sentences ko combine karke meaningful blocks banaye taaki LLM ko behtar context mile.
* **ChromaDB Integration:** Pandas/Joblib se shift karke industry-standard ChromaDB Vector Database lagaya jo scaling ke liye best hai.
* **Timestamp Formatting:** Seconds (139.0s) ko professional MM:SS format mein badla.
* **Prompt Engineering:** General prompt ko ek strict AI Teaching Assistant Prompt mein upgrade kiya jisme hallucination rokne ke liye fallback rules aur constraints hain.

## ⚠️ 3. Problems Faced & How We Solved Them (Aayi Hui Rukawatein aur Solutions)
* **Problem 1: ModuleNotFoundError for Whisper & MoviePy**
  * *Reason:* Virtual environment (`AIassisTeacher`) ke andar packages install nahi the.
  * *Solution:* `pip install openai-whisper moviepy sentence-transformers chromadb groq python-dotenv` run karke dependencies set kiin.
* **Problem 2: SyntaxError: invalid decimal literal**
  * *Reason:* Python mein kisi bhi file/module ka naam number se start nahi ho sakta (`1_transcribe.py`).
  * *Solution:* File ke naam se numbers hata kar clean naam (`transcribe.py`) rakhe.
* **Problem 3: MoviePy v2.x Import Error (`ModuleNotFoundError: No module named 'moviepy.editor'`)**
  * *Reason:* MoviePy ke naye version mein `moviepy.editor` module ko remove kar diya gaya hai.
  * *Solution:* Import ko update karke `from moviepy import VideoFileClip` kar diya.
